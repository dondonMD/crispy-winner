All HTTP uses an in-process MockTransport with 150ms response delay and the production shared provider limiter. No provider transport/enrichment task is started. Monitoring stand-in requests demonstrate shared-limiter progress, not completed real security scans. The consumer runs unprofiled for latency measurements; a separate initial analysis/refresh is cProfiled. Inclusive stage timers are reported without summing overlapping stages as exclusive CPU. Trade application age uses scheduled event time, so event-loop stalls cannot be hidden by assigning a later arrival timestamp.

Commands are bounded to <=600 seconds and <=100 trades/s; percentile buffers have a corresponding hard 60,000-event limit. JSON/profile outputs refuse overwrite.
