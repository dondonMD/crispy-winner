# helius

Verified: 2026-10-08 (documentation, not service SLA).

Purpose: Optional RPC replacement

Official documentation: https://www.helius.dev/docs

Endpoints/features: Standard Solana JSON RPC through configured SOLANA_RPC_URL

Authentication / free vs paid: Optional key in private .env. Free/paid plan varies; no enhanced streaming required.

Rate limits: Same local limiter as RPC; provider plan quotas apply.

Limitations / fallback: No separate SDK or paid enhanced service dependency. Public RPC is baseline.
