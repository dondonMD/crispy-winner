# CRISPY WINNER development rules
Local-first modular monolith: Python, SQLite WAL, compiled React. No autonomous live trading, wallet secrets, telemetry, or private order flow. All economics and evaluation use after-cost returns; unknown data fails closed. Default paper account $20. Bound queues, candidates and rolling buffers; enforce retention without deleting paper history or strategy versions. Verify integrations against official current documentation. No production mocks, empty services or TODO stubs. Demo data must be explicitly labelled and isolated. Test relevant changes before meaningful stage commits and pushes to main. Never commit secrets, overwrite unrelated work, force push or rewrite published history. Record limitations and measured resource results honestly. Strategy changes require immutable versions and time-based evaluation.
